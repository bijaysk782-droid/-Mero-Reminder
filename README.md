# Mero Reminder — Flutter starter

यो prototype ले Driving License, Bluebook/Tax, Insurance, Passport, Warranty, Subscription आदि expiry date राख्ने basic UI देखाउँछ।

## Run
1. Flutter SDK install गर्नुहोस्।
2. यो project folder खोल्नुहोस्।
3. `flutter pub get`
4. `flutter run`
